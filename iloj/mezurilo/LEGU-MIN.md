# ⟨ ការវាស់សមត្ថភាព 📏 ⟩

ឧបករណ៍វាស់ទាំងនេះរត់លើ Node ដោយបង្គំកូដពិតរបស់ហ្គេម ។ វាជំនួស DOM ដោយ
ដុំពុម្ពក្លែងក្លាយ ( `falsdomo.mjs` ) ដើម្បីឱ្យអនុគមន៍លេខអាចវាស់បានស្របគ្នារាល់ដង ។

## របៀបរត់ 🛠️

```
npx rolldown iloj/mezurilo/<ឯកសារ>.ts -o iloj/mezurilo/<ឯកសារ>.mjs --format esm --platform node
node --import ./iloj/mezurilo/falsdomo.mjs iloj/mezurilo/<ឯកសារ>.mjs
```

ម៉ូឌុលភាសាមិនបោះពុម្ពអ្វីនៅពេលផ្ទុកទេ ។ ការបម្លែងសំឡេងដែលត្រូវមើល
ស្ថិតក្នុង `sonaj-provoj.ts` ។ ដូច្នេះលទ្ធផលឧបករណ៍វាស់មានតែលេខរបស់វា ។

## ការវាស់ដោយប្រវត្តិរូប 🔬

ដើម្បីរកចំណុចក្តៅក្នុងការផ្ទុក ៖

```
node --cpu-prof --cpu-prof-dir=iloj/mezurilo/prof --import ./iloj/mezurilo/falsdomo.mjs iloj/mezurilo/<ឯកសារ>.mjs
```

ឯកសារ `.cpuprofile` អាចអានដោយ Chrome DevTools ឬដោយស្គ្រីបតូចមួយដែល
បូកការចំណាយផ្ទាល់ខ្លួនតាមអនុគមន៍ ។ សូមលុបថត `prof` ក្រោយប្រើ ។

## ចំណាំ 📝

ម៉ាស៊ីនមានសំឡេងច្រើន ។ តម្លៃ `min` នៃជុំជាច្រើនអាចទុកចិត្តបានជាង `mediano` ។
