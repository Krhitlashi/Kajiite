# ≺⧼ ការវាស់សមត្ថភាព 📏 ⧽≻

ឧបករណ៍វាស់ទាំងនេះរត់លើ Node ដោយបង្គំកូដពិតរបស់ហ្គេម ។ វាជំនួស DOM ដោយ
ដុំពុម្ពក្លែងក្លាយ ( `falsdomo.mjs` ) ដើម្បីឱ្យអនុគមន៍លេខអាចវាស់បានស្របគ្នារាល់ដង ។

## ⟪ របៀបរត់ 🛠️ ⟫

```
node iloj/mezurilo/konstruu.mjs            # សាងសង់ .ts ទាំងអស់ទៅ .mjs
node iloj/mezurilo/konstruu.mjs provo      # សាងសង់តែឯកសារមួយ
node --import ./iloj/mezurilo/falsdomo.mjs iloj/mezurilo/<ឯកសារ>.mjs [អាគុយម៉ង់]
```

ឯកសារ `.mjs` ជាលទ្ធផលសាងសង់ ៖ មិនរក្សាទុកក្នុង git ទេ ( មើល `.gitignore` ) ។
មានតែ `falsdomo.mjs` ដែលសរសេរដោយដៃ ។

ម៉ូឌុលភាសាមិនបោះពុម្ពអ្វីនៅពេលផ្ទុកទេ ។ ការបម្លែងសំឡេងដែលត្រូវមើល
ស្ថិតក្នុង `sonaj-provoj.ts` ។ ដូច្នេះលទ្ធផលឧបករណ៍វាស់មានតែលេខរបស់វា ។
